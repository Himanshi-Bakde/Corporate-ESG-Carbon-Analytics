# Corporate-ESG-Carbon-Analytics

## 📌 Project Overview
The Corporate ESG and Carbon Analytics system is a data-driven sustainability framework designed to track, analyze, and report corporate environmental and operational metrics.

---

## 🛠️ Tech Stack & Tools
* **Languages:** Python (Pandas, NumPy, Boto3, SQLite)
* **Cloud & Storage:** AWS S3, AWS IAM
* **Data Visualization:** Power BI
* **Version Control:** Git & GitHub

---

## 🚀 Key Features
1. **Automated Data Generation:** Simulates Scope 1 and Scope 2 emissions and operational costs.
2. **Secure Cloud Integration:** Pushes data assets directly to AWS S3 data lakes.
3. **Power BI Reporting:** Translates raw analytics files into high-level strategic insights.
